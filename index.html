Travel Booking — Multi-Agent System

A LangGraph Planner Agent books a full trip by calling MCP tools for flights, hotels and cabs in sequence, then hands the itinerary to a separate FastAPI Confirmation Agent. Enter a trip and watch every agent step, tool call and response.

⚡ This demo runs the same graph and tool contracts in your browser. In the repo, the tools run on a FastMCP server (port 8000) and the confirmation agent runs on FastAPI (port 6004).

Architecture

  • Planner Agent: a LangGraph StateGraph with typed TravelState, where each node is an async tool call
  • MCP Server: FastMCP exposes book_flight, book_hotel and book_cab as tools
  • Confirmation Agent: a FastAPI service that receives the bookings and returns a task_id
  • Client: a CLI that collects trip details and invokes the graph

graph = StateGraph(TravelState)
graph.add_node("book_flight", book_flight)
graph.add_node("book_hotel", book_hotel)
graph.add_node("book_cab", book_cab)
graph.add_node("confirm", send_to_confirmation_agent)
graph.set_entry_point("book_flight")
graph.add_edge("book_flight", "book_hotel")
graph.add_edge("book_hotel", "book_cab")
graph.add_edge("book_cab", "confirm")
graph.add_edge("confirm", END)
app = graph.compile()
